# CredWatch synthetic detection fixtures

This repository is a controlled public detection experiment. All sample credentials
are locally generated, unissued test values. The SSH key has never been registered
on a host. These samples must never be used to access a service or protect data.
Database and host names use reserved .invalid domains.

Each samples/ file is one labeled publication event. There are six positive format
examples and two negative examples. Results count synthetic detection only;
they are not discoveries of real leaked accounts. No workflow or executable service
is included. Do not attempt credential validation.
